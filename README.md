# Wither Rose Gold

A sister mod to [Rose Gold Equipment](https://github.com/jeejeekay/rose-gold-equipment) (**required**).
Upgrades rose gold tools and armor to wither rose gold in the smithing table.

Same layout as RGE: one branch per Minecraft version (`mc/1.21.11`, `mc/26.1`, `mc/26.2`, `mc/26.3`),
each with a `neoforge/` and a `fabric/` folder.
